This report answers the following questions:

- Which service control and resource control policy statements on an account's path match a given action?
- Is the action denied, conditionally denied, or allowed by the service control policies at every level?
- At which level is an allow for the action missing?

The result is based on the policy documents only. It doesn't evaluate condition keys, IAM policies or resource policies. Service control policies and resource control policies don't apply to the management account.

This dashboard must be run against the organization's management account or a delegated administrator account.
