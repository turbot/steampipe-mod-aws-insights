This report answers the following questions:

- Which organizational units are in the organization, and what is each one's path from the root?
- How many child organizational units and accounts does each organizational unit contain?
- Which organizational units are empty?
- Which policies are attached directly to each organizational unit?

Only policies attached directly to an organizational unit are listed. Policies inherited from the root or a parent organizational unit are shown on the Organizational Unit Detail dashboard.

This dashboard must be run against the organization's management account or a delegated administrator account.
